# Public / Private Boundary

This starter composes only public reliability primitives and a small neutral runtime shell.

## Public

- capability validation;
- deterministic policy evaluation;
- local inference health observation;
- optional loopback OpenAI-compatible inference call;
- exact operator-declared executable + argv binding;
- governed execution;
- public Agent Receipt chain;
- public Agent Run Manifest;
- synthetic examples and adversarial tests;
- public-safe micro-plugins (`compile_context_packet`, `choose_cheapest_capable_route`, `public_proof_card`, `diff_public_state`, `compile_handoff_packet`) and the Agent Plugin wrapper that calls the first three.

## Private and not included

- AXON production implementation or mutation authority;
- AEGIS/IAR routing intelligence;
- Governance Core production policy/trust configuration;
- Mother/Father orchestration;
- LandOS, Territory or Recipe Engine intelligence;
- DeedSonar logic/data;
- private memory, prompts, datasets, customer data or connectors;
- proprietary scoring/ranking;
- production authority topology.

The starter is an independent reference runtime, not a reduced copy of the private organism.
